```
┌──────────────────┐          HTTP           ┌──────────────────────────┐

│                   │                         │                           │
│  ┌─────────────┐ │  POST /recall           │  ┌─────────────────────┐ │
│  │ MemoryTen-  │ │ ──────────────────────► │  │  TdaiGateway        │ │
│  │ centdbPro-  │ │ ◄────────────────────── │  │  server.ts          │ │
│  │ vider       │ │  JSON response          │  │                     │ │
│  │             │ │                         │  │  Standalone-        │ │
│  │  • prefetch │ │  POST /capture           │  │  HostAdapter        │ │
│  │  • sync_turn│ │ ──────────────────────► │  │                     │ │
│  │  • shutdown │ │ ◄────────────────────── │  │  TdaiCore            │ │
│  └─────┬───────┘ │                         │  └─────────────────────┘ │
│        │         │                         │                           │
│  ┌─────▼───────┐ │  Gateway 生命周期管理     │  ┌─────────────────────┐ │
│  │ Gateway-    │ │                        │  │  StandaloneLLMRunner │ │
│  │ Supervisor  │ │  spawn / health check   │  │                     │ │
│  │             │ │ ◄─────────────────────► │  │  直接调用 OpenAI API  │ │
│  │  • ensure_  │ │                        │  │  使用 @ai-sdk/openai │ │
│  │    running  │ │                        │  │                     │ │
│  │  • shutdown │ │                        │  └─────────────────────┘ │
│  └─────────────┘ │                         └──────────────────────────┘
└──────────────────┘

数据流:
  Python Provider → HTTP Client → Gateway Server
  → StandaloneHostAdapter(上下文/日志/LLM) → TdaiCore 执行
  LLM 调用: TdaiCore → StandaloneLLMRunner → Vercel AI SDK → OpenAI API

三层组件:
  1. Provider 层 — hermes-plugin/memory/memory_tencentdb/
     __init__.py (MemoryTencentdbProvider) + client.py (HTTP SDK) + supervisor.py (进程管理)

  2. Gateway Server 层 — src/gateway/
     server.ts (TdaiGateway, 路由: /health /recall /capture /search/* /session/end /seed)
     + config.ts (YAML+环境变量) + types.ts (请求/响应类型)

  3. Standalone 适配器层 — src/adapters/standalone/
     host-adapter.ts (StandaloneHostAdapter) + llm-runner.ts (Vercel AI SDK 直连)
```

### 6.3 架构维度对比

```
模式 A (进程内)                          模式 B (HTTP Sidecar)
─────────────────────                   ───────────────────────

集成:  同进程 Node.js 插件                集成:  独立 HTTP 进程 + 跨语言 Client
通信:  直接函数调用                       通信:  HTTP JSON (localhost:8420)
LLM:   复用宿主 runEmbeddedPiAgent       LLM:   独立 Vercel AI SDK 直连
配置:  宿主配置文件                       配置:  YAML + 环境变量
生命:  随宿主进程启停                     生命:  Gateway 独立管理, Supervisor 管控
数据:  ~/.openclaw/memory-tdai/         数据:  ~/.memory-tencentdb/memory-tdai/
容错:  宿主框架级                         容错:  熔断器 + 看门狗 + 自动恢复
适用:  平台有 Node.js 插件 SDK            适用:  任何语言, 通过 HTTP 即可接入
```

### 6.4 LLM Runner 调用路径对比

```
L1 提取/L1 去重 (enableTools=false)
  OpenClaw:  TdaiCore → OpenClawLLMRunner → CleanContextRunner → runEmbeddedPiAgent
  Gateway:   TdaiCore → StandaloneLLMRunner → AI SDK generateText() → OpenAI API

L2 场景/L3 画像 (enableTools=true)
  OpenClaw:  TdaiCore → OpenClawLLMRunner → CleanContextRunner(工具循环) → runEmbeddedPiAgent
  Gateway:   TdaiCore → StandaloneLLMRunner → AI SDK maxSteps=20 (文件工具+路径沙箱) → OpenAI API
```

## 八、Hermes Provider 生命周期时序

```
  Hermes框架    MemoryTencentdbProvider    GatewaySupervisor    Gateway Server    TdaiCore
  ──────────    ──────────────────────     ────────────────     ─────────────     ────────

  === 初始化阶段 ===

  is_available() ──►
                    GET /health ──────────────────────────────►
                    ◄── { status: "ok" } ──────────────────────

  initialize() ───►
                    ensure_running() ──────►
                                            spawn Gateway ────────►
                                            轮询 GET /health ──────►
                                            ◄── { status: "ok" } ───
                    ◄── 就绪
                    启动看门狗线程 (10s 轮询)

  === 运行时阶段 ===

  prefetch(query) ►
                    POST /recall { query, session_key } ────────►
                                                              handleBeforeRecall()
                    ◄── { context, strategy } ────────────────────

  sync_turn(u,a) ►
                    后台 daemon 线程 (最多4并发):
                    POST /capture { ... } ──────────────────────►
                                                              handleTurnCommitted()
                    ◄── { l0_recorded, ... } ─────────────────────

  handle_tool_call►
  ("memory_search")
                    POST /search/memories { query, ... }────────►
                                                              searchMemories()
                    ◄── { results, total } ──────────────────────

  === 关闭阶段 ===

  shutdown() ────►
                    停止看门狗, join所有sync线程
                    POST /session/end ─────────────────────────►
                                                              handleSessionEnd()
                    释放 supervisor 引用

  注意: Gateway 不随 Provider 关闭而关闭 — 可被多个 session 复用
```

## 九、各平台事件 → TdaiCore 映射总表

| TdaiCore 方法 | OpenClaw (模式A) | Hermes (模式B) | Claude Code (模式B) |
|--------------|-----------------|---------------|-------------------|
| `initialize()` | `register()` 中调用 | `TdaiGateway.start()` | `ensureGateway()` → Gateway 自初始化 |
| `handleBeforeRecall()` | `api.on("before_prompt_build")` | `provider.prefetch(query)` → `POST /recall` | `UserPromptSubmit` hook → `POST /recall` |
| `handleTurnCommitted()` | `api.on("agent_end")` | `provider.sync_turn(u,a)` → `POST /capture` | `Stop` hook → `POST /capture` |
| `searchMemories()` | `api.registerTool("tdai_memory_search")` | `handle_tool_call("memory_tencentdb_memory_search")` → `POST /search/memories` | MCP tool → `POST /search/memories` |
| `searchConversations()` | `api.registerTool("tdai_conversation_search")` | `handle_tool_call("memory_tencentdb_conversation_search")` → `POST /search/conversations` | MCP tool → `POST /search/conversations` |
| `handleSessionEnd()` | `gateway_stop` 统一处理 | `post_session_sync()` → `POST /session/end` | 暂无独立事件 |
| `destroy()` | `api.on("gateway_stop")` | `TdaiGateway.stop()` | Gateway 独立管理生命周期 |
